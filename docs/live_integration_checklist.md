# 后续实盘接入前置清单

只有全部完成后，才进入实盘适配阶段：

- [ ] 明确开户证券公司
- [ ] 获得正规Python程序化交易接口
- [ ] 确认接口支持ETF查询、报单、撤单、委托和成交查询
- [ ] 按券商要求完成程序化交易信息报告
- [ ] 完成不少于一个完整市场周期的模拟运行
- [ ] 订单唯一编号和幂等测试通过
- [ ] UNKNOWN订单不得自动重发
- [ ] 断网、重启和客户端退出测试通过
- [ ] 资金、持仓、委托和成交四方对账通过
- [ ] 交易日历、停牌和不可成交处理通过
- [ ] 人工停止开关通过
- [ ] 初期实盘采用人工确认和小额资金
