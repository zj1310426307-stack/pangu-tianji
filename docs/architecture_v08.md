# 盘古·天机 v0.8 架构与状态边界

## 数据与研究链

```text
同花顺金融数据 API（X-api-key，仅进程环境）
  → 历史日线响应合同校验
  → 四ETF完整批次校验
  → 本地CSV与无密钥manifest
  → 趋势/动量策略
  → 硬风控
  → MockBroker模拟成交
  → SQLite审计记录
  → 不可变运行快照
  → 网页复盘 / 可选模型解释
```

数据适配器负责 HTTP 鉴权、业务响应信封、字段映射和缓存原子写入。策略服务只接收统一的 OHLCV DataFrame，不知道 API Key 或 HTTP 细节。

## 状态所有权

| 状态 | 唯一所有者 | 网页权限 | 模型权限 |
|---|---|---|---|
| API Key | 操作系统进程环境 | 只能看到“已配置/未配置” | 无 |
| 历史行情缓存 | `ThsFinanceDataProvider` | 只读日期与来源 | 只读已固化快照 |
| 回测运行状态 | `RunService` | 本地启动/安全停止 | 无 |
| 模拟资金与持仓 | `MockBroker` | 只读运行结果 | 无 |
| 风控放行 | `RiskEngine` | 无修改入口 | 无 |
| 模型连接 | `ModelService` | 测试连接/请求解释 | 只能解释完成快照 |

## 失败关闭

- 缺少或无效 API Key 且没有可信缓存：拒绝运行。
- 业务 `code != 0`：拒绝把响应写入缓存。
- 四只 ETF 任一下载或校验失败：整批不替换活动缓存。
- 缓存 provider 不是 `ths_finance`：拒绝回退。
- 缓存晚于配置结束日超过允许天数：拒绝回退。
- 当前配置不是 paper 或开启实盘：应用启动即拒绝。

## 明确未连接

v0.8 没有同花顺证券客户端、SuperMind、QMT、PTrade或任何券商订单接口。历史行情数据接入不等同于交易账户接入，也不会自动获得模拟盘或实盘权限。
